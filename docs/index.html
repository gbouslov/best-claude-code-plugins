Best Claude Code plugins for web development

Start with Feature Dev for a feature in an existing application, Context7 for library APIs and Playwright for the running browser journey. Add Supabase, Firebase, Stripe or Vercel when that service is part of the job.

For a frontend change, the useful sequence is concrete: understand the component, check the relevant library API, implement it, and check the result in a browser. Add the plugin covering the step your current setup is missing.

Best Claude Code plugins for frontend design or website design

Use Figma when you have a design file to implement: it connects Claude to design context and component mappings. Use Playwright to inspect the implemented page and its interactions, then Code Simplifier for focused cleanup. Bring the actual design, content and acceptance criteria to the task.

Figma access and browser testing solve different problems. Choose the design connection for source designs and the browser connection for the page people will use.

Best Claude Code plugins for mobile app development

For app development, Superpowers supplies planning, debugging and verification workflows, while Context7 helps with framework documentation. Firebase, Supabase and Sentry fit the backend and production-error parts of a mobile app when you already use those services.

Use your platform's simulator, device and build tools to verify native behavior. Playwright fits web pages and mobile web journeys. For Expo, React Native, Flutter or iOS-specific workflows, the companion Best Claude Code Skills list is forthcoming and covers those specialist collections.

Best Claude Code plugins for developers

Pick the missing development step: Serena for symbols and references, Code Review for a GitHub pull request, PR Review Toolkit for selected review concerns, and Commit Commands for explicit Git commit and PR commands. GitHub, GitLab, Linear and Atlassian connect the service where the work is tracked.

For a developer building an agent application itself, Agent SDK Dev targets Python and TypeScript SDK projects. The overlap table helps avoid adding two packages for the same step.

Plugins and skills, compared

A skill is reusable task guidance in a folder containing SKILL.md. A plugin is an installable package that can include skills, agents, hooks and MCP connections; an MCP server supplies tools or data access. Choose a skill for a focused workflow, a plugin for a packaged setup, and a server when you need a connection. Official component overview.

For example, Supabase's plugin combines guidance with a live service connection; a skills-only installation can supply SQL guidance without that connection. The forthcoming Best Claude Code Skills companion covers document, web, mobile, security and research skills. A skill's portability does not automatically carry a plugin's hooks or server configuration to another agent.

Install and manage

The fenced sh commands on this page run in your terminal. Commands beginning with /, such as /reload-plugins, run inside Claude Code.

Register Anthropic's marketplace once if it is not already available:

claude plugin marketplace add anthropics/claude-plugins-official

The install commands below use --scope local: enable the plugin for you in the current repository. Use --scope user for all your projects, or --scope project for a shared repository setup. Community entries include their own marketplace registration command. A marketplace's registered name can differ from its GitHub repository name.

After installing, run /reload-plugins if Claude Code requests it, or start a new session. Check the Installed tab in /plugin and use /mcp for bundled server connection status. Some entries need a sign-in, runtime or one-time setup before their tools work. Official installation and scope guide.

To list installed plugins and registered marketplaces, run these in your terminal:

claude plugin list
claude plugin marketplace list

To browse available plugins, open /plugin inside Claude Code and choose Discover. Your installed list and the available marketplace catalog serve different purposes.

To manage one package, use its qualified name and intended scope:

claude plugin update feature-dev@claude-plugins-official
claude plugin disable feature-dev@claude-plugins-official --scope local
claude plugin enable feature-dev@claude-plugins-official --scope local
claude plugin uninstall feature-dev@claude-plugins-official --scope local

The plugin commands reference explains scope defaults and flags. See the FAQ for updating a whole marketplace's installed plugins.

Troubleshooting GitHub plugin auth and setup

First identify which connection failed: downloading a marketplace from GitHub, connecting the GitHub MCP service, or running a command that uses GitHub CLI. Their credentials and failure messages can differ.

  1. For a marketplace clone error, confirm the owner/repo exists and you can access it. git ls-remote <repository-url> checks Git access; a private repository requires non-interactive authentication. GitHub CLI users can configure Git with gh auth login followed by gh auth setup-git. See the official authentication troubleshooting steps.
  2. For the listed GitHub plugin, inspect /mcp inside Claude Code. Its checked wrapper expects the GITHUB_PERSONAL_ACCESS_TOKEN environment variable; a successful marketplace download does not configure this server. Follow GitHub MCP authentication for your host and account.
  3. For Code Review or Commit Commands, check gh auth status in the terminal and the repository access the command requires. If a newly installed plugin is missing, inspect the Errors tab of /plugin, check the marketplace name and run /reload-plugins. Plugin troubleshooting.

Keep credential values out of issue reports. Share the command, error text with secrets removed, Claude Code version, and whether the failure is in cloning, loading or connecting a server.

Three small setups for real work

Ship a feature: use Feature Dev to explore and plan the change. Add Context7 when a library API is uncertain. Add Playwright when you need to check the user journey in the running application. Each plugin addresses a different part of the task.

Fix a production bug: use Sentry to understand the error. Add Serena when tracing symbols across the codebase becomes the bottleneck. Reproduce the failure and verify the fix with your project's tests or Playwright. Error data and source access should match the project you are working on.

Continue a long project: start with Planning with Files when the missing thing is an explicit plan. Add Claude HUD for visibility. Consider Claude-Mem only when cross-session retrieval is useful; consider Context Mode when large outputs are consuming the context window. These solve different problems, so add them when the problem appears.

How to choose and keep your setup useful

Pick a plugin for a task you can name. Read its primary source and inspect what /plugin says it will install. Skills and commands add instructions; agents run specialized work; hooks run at lifecycle events; MCP servers connect tools and data. A plain skills install can omit a plugin's hooks or server configuration.

For a service connection, check the account, permissions and test/live environment. For a local MCP process or hook, check the runtime, code and background behavior. Installing a plugin is not a security review. A recent commit or a large star count does not prove safety.

Check for duplicate MCP connections and overlapping workflow instructions before adding another plugin. Inspect /context after setup to see what is using the window. Third-party marketplaces normally require you to enable automatic updates or update manually; review updates that change permissions or background behavior. Plugin security and trust.

Alternatives

For a single reusable workflow, a standalone skill can be sufficient; the forthcoming Best Claude Code Skills list compares collections by task. For tools or live data alone, configure an MCP server. For repository conventions, Claude Code's memory and instructions can hold the shared guidance.

If your comparison is Claude Code plugins versus GitHub Copilot, Copilot on GitHub offers repository chat, coding tasks and pull-request review. Choose the host that fits where you work, then check which extensions it supports; a Claude Code plugin package is not automatically a Copilot extension.

Frequently asked questions

What are Claude Code plugins?

Plugins package reusable components such as skills, agents, hooks and MCP connections for installation together. The component overview explains what each part adds; individual entries above identify the parts in that package.

What is the difference between skills and plugins in Claude Code?

A skill teaches a reusable task through SKILL.md; a plugin distributes a setup that can include that skill and other components. Choose a standalone skill when you need the instructions alone, or a plugin when you want the surrounding agents, hooks or connections. See plugins and skills, compared.

What are the best Claude Code plugins?

Start with your next job: Feature Dev for exploring and building a feature, Context7 for library documentation, and Playwright for a running web journey. Choose Figma for a source design or Sentry for production-error context; the one-minute table compares the setup each adds.

How to install Claude Code plugins?

Use claude plugin install <plugin>@<marketplace> --scope local in a terminal after registering the marketplace. Each entry above gives its specific command and prerequisites; /reload-plugins inside Claude Code loads a newly installed package into an existing session. Install and manage.

How to install Claude Code plugins from GitHub?

Register the publisher's marketplace with claude plugin marketplace add owner/repo, then install the plugin using that marketplace's registered name. A repository containing a skill alone is a different package type; use its upstream skill installation guide. Marketplace setup.

How to list Claude Code plugins?

Run claude plugin list in the terminal for installed plugins, or open /plugin inside Claude Code. Use its Discover view for available plugins and claude plugin marketplace list for registered catalogs. Command reference.

Are Claude Code plugins free?

The entries link to publicly accessible packages, each with its own license. Model usage, connected services and compute can cost money; check the entry's setup notes and upstream terms before choosing a package.

How to update all Claude Code plugins?

Open /plugin, select a marketplace in Marketplaces, and choose Update marketplace to refresh that catalog and its installed plugins; some source types still need individual updates. The shell command claude plugin marketplace update refreshes listings, while claude plugin update <plugin>@<marketplace> updates a selected package. Update behavior and exceptions.

How to uninstall Claude Code plugins?

Run claude plugin uninstall <plugin>@<marketplace> --scope local for a local installation, or choose the corresponding scope in /plugin. Use disable when you want to stop a plugin while keeping it installed. Command reference.

Are Claude Code plugins safe?

Review the package and its access before enabling it: hooks can execute commands, and servers can reach data and services with your permissions. Inspect the specific components, runtimes and accounts listed above and follow Anthropic's security and trust guide; repository popularity is one signal about adoption, not a security assessment.
